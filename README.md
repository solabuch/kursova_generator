# Курсова 2.0: AI Генератор Наукових Робіт

Потужний інструмент для автоматизованого написання курсових та наукових робіт за допомогою штучного інтелекту (**OpenAI GPT**) та веб-пошуку (**DuckDuckGo**).

Система використовує мульти-агентний підхід (Planner -> Researcher -> Writer) для створення якісного, структурованого та фактологічно обґрунтованого контенту.

---

## 🚀 Основні Можливості (Версія 3.0)

*   **Мульти-агентна архітектура**:
    *   **Planner**: Аналізує зміст, визначає тип розділу (теорія/практика) та ключові сутності для пошуку.
    *   **Researcher**: Автоматично шукає актуальну інформацію, статистику та дані про компанії в інтернеті.
    *   **Writer**: Генерує текст, використовуючи знайдені дані та дотримуючись академічного стилю.
*   **Розумне форматування (V3)**:
    *   Автоматичне форматування заголовків: `РОЗДІЛ N НАЗВА` (CAPS) для розділів, `N.M Назва` для підрозділів.
    *   Коректна обробка спецрозділів: ВСТУП, ВИСНОВКИ, РЕЗЮМЕ.
*   **Академічне цитування**:
    *   Розумний алгоритм розстановки посилань (починаючи з 4-го абзацу, з інтервалом ~3 абзаци).
    *   Автоматична генерація списку використаних джерел (`_sources.txt`) з дедублікацією.
*   **Два режими роботи**:
    *   🖥️ **GUI**: Зручний графічний інтерфейс (`customtkinter`).
    *   💻 **CLI**: Консольний режим для швидкого запуску на сервері.

## 📂 Структура Проєкту

```text
kursova_generator/
├── core/                   # Ядро системи (агенти, логіка)
│   ├── orchestrator.py     # Головний контролер процесу
│   ├── researcher.py       # Агент пошуку (DuckDuckGo)
│   └── toc_parser.py       # Парсер змісту
├── input/
│   └── toc.txt             # Вхідний файл змісту
├── output/                 # Папка з результатами
│   └── {Тема роботи}/      # Генерація конкретної роботи
│       ├── _final_course_paper.txt  # Фінальний документ
│       └── _sources.txt             # Список джерел
├── prompts/                # Системні промпти для AI
├── config.yaml             # Головний конфіг
├── main.py                 # Запуск через консоль
└── gui.py                  # Запуск графічного інтерфейсу
```

## 🛠️ Встановлення

1.  **Клонуйте репозиторій**:
    ```bash
    git clone <URL_репозиторію>
    cd kursova_generator
    ```

2.  **Створіть віртуальне середовище** (рекомендовано):
    ```bash
    python -m venv venv
    # Windows:
    venv\Scripts\activate
    # macOS/Linux:
    source venv/bin/activate
    ```

3.  **Встановіть залежності**:
    ```bash
    pip install -r requirements.txt
    ```

## ⚙️ Налаштування

### 1. API Ключі
Створіть файл `.env` у корені проєкту та додайте ваш OpenAI ключ:
```env
OPENAI_API_KEY=sk-proj-...
```
*Альтернатива*: Можна прописати ключ прямо в `config.yaml`, але це менш безпечно.

### 2. Конфігурація (`config.yaml`)
Основні параметри, які можна змінити:
*   `active_provider`: `openai`
*   `model`: `gpt-4o` (рекомендовано) або `gpt-4-turbo`.
*   `project_settings`:
    *   `topic`: Тема вашої роботи.
    *   `methodology_summary`: Короткий опис методів дослідження.

### 3. Зміст (`input/toc.txt`)
Підготуйте файл змісту. Формат має чітку ієрархію за допомогою відступів (4 пробіли):

```text
ВСТУП
РОЗДІЛ 1 ТЕОРЕТИЧНІ ОСНОВИ...
    1.1 Сутність поняття...
    1.2 Класифікація...
РОЗДІЛ 2 АНАЛІЗ ДІЯЛЬНОСТІ...
    2.1 Загальна характеристика...
ВИСНОВКИ
```

## ▶️ Використання

### Варіант А: Графічний Інтерфейс (GUI)
Найзручніший спосіб. Дозволяє редагувати тему, завантажувати зміст та бачити прогрес.
```bash
python gui.py
```

### Варіант Б: Консоль (CLI)
Для автоматизованого запуску. Переконайтесь, що `config.yaml` налаштований правильно.
```bash
python main.py
```

## 📄 Результати

Після завершення роботи (5-10 хвилин) перевірте папку `output/{Тема роботи}/`:
1.  **`_final_course_paper.txt`**: Повний текст роботи з усіма розділами, форматуванням та посиланнями.
2.  **`_sources.txt`**: Список усіх використаних джерел.
3.  **`levelX_....txt`**: Окремі файли кожного розділу (для зручності редагування).

## 💡 Поради для кращого результату
*   **Детальний зміст**: Чим детальніші підпункти в `toc.txt`, тим краще AI розкриє тему.
*   **Тема**: Вказуйте повну, конкретну тему в конфізі або GUI.
*   **GPT-4**: Використання моделі GPT-4 значно підвищує якість аналітики та логічність структури порівняно з GPT-3.5.
