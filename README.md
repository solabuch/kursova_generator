# Курсова 2.0: AI Генератор Наукових Робіт

Потужний інструмент для автоматизованого написання курсових та наукових робіт за допомогою штучного інтелекту (**OpenAI GPT**) та веб-пошуку (**DuckDuckGo**).

Система використовує мульти-агентний підхід (Planner -> Researcher -> Writer) для створення якісного, структурованого та фактологічно обґрунтованого контенту.

---

## 🚀 Основні Можливості

*   **Мульти-агентна архітектура**:
    *   **Planner**: Аналізує зміст, визначає тип розділу (теорія/практика) та ключові сутності для пошуку.
    *   **Researcher**: Автоматично шукає актуальну інформацію, статистику та дані про компанії в інтернеті.
    *   **Writer**: Генерує текст, використовуючи знайдені дані та дотримуючись академічного стилю.
*   **Веб-інтерфейс (Web UI)**:
    *   Сучасний темний дизайн.
    *   Редактор змісту (Drag & Drop рівні, додавання/видалення пунктів).
    *   Логи генерації в реальному часі.
*   **Розумне форматування**:
    *   Автоматичне форматування заголовків.
    *   Коректна обробка спецрозділів: ВСТУП, ВИСНОВКИ, РЕЗЮМЕ.
*   **Академічне цитування**:
    *   Розумний алгоритм розстановки посилань (інтелектуальна частота цитування).
    *   Автоматична генерація списку використаних джерел із сортуванням.

## 📂 Структура Проєкту

```text
kursova_generator/
├── core/                   # Ядро системи (агенти, логіка)
├── web/                    # Веб-інтерфейс (Flask + HTML/JS)
│   ├── templates/          # HTML шаблони
│   ├── static/             # CSS/JS
│   └── app.py              # Веб-сервер
├── input/
│   └── toc.txt             # Вхідний файл змісту (опціонально)
├── output/                 # Папка з результатами
├── config.yaml             # Головний конфіг
└── main.py                 # CLI (консольна версія)
```

## 🛠️ Встановлення

1.  **Клонуйте репозиторій**:
    ```bash
    git clone <URL_репозиторію>
    cd kursova_generator
    ```

2.  **Створіть віртуальне середовище**:
    ```bash
    python -m venv venv
    # Windows:
    venv\Scripts\activate
    # macOS/Linux:
    source venv/bin/activate
    ```

3.  **Встановіть залежності**:
    ```bash
    pip install -r requirements.txt
    ```

---

## ⚙️ Налаштування

### 1. API Ключі
Створіть файл `.env` у корені проєкту та додайте ваш OpenAI ключ:
```env
OPENAI_API_KEY=sk-proj-...
```

---

## ▶️ Використання

### 🌐 Веб-інтерфейс (Рекомендовано)
Запустіть локальний сервер та відкрийте браузер.
```bash
python web/app.py
```
Перейдіть за адресою: `http://127.0.0.1:5000`

### 💻 Консоль (CLI)
Для автоматизованого запуску без інтерфейсу.
```bash
python main.py --topic "Ваша тема"
```

## 📄 Результати

2.  **`_sources.txt`**: Список джерел.
