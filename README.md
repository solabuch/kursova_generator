## Огляд

AI Генератор Курсових Робіт — це Python-застосунок для автоматизованого створення структурованих академічних робіт за допомогою **мульти-агентного AI пайплайну**. Система розбиває зміст на окремі розділи, класифікує кожен як теоретичний або практичний, проводить веб-дослідження через DuckDuckGo в реальному часі та генерує готовий до публікації текст з коректними академічними посиланнями — все це через зручний веб-інтерфейс або командний рядок.

## Можливості

- **🤖 Мульти-агентний пайплайн** — три спеціалізовані AI агенти працюють послідовно:
  - **Планувальник (Planner)** — аналізує зміст, класифікує розділи (теорія / практика), визначає сутності для дослідження
  - **Дослідник (Researcher)** — автоматично збирає релевантні дані, статистику та інформацію з інтернету через DuckDuckGo
  - **Автор (Writer)** — генерує текст академічного стилю з використанням зібраних даних та контексту попередніх розділів

- **🧠 Розумне управління контекстом** — відстеження токенів із автоматичною сумаризацією при наближенні до лімітів моделі (на базі `tiktoken`)

- **📚 Система академічного цитування** — інтелектуальне розміщення посилань із налаштовуваною частотою, автоматична генерація списку джерел та перенумерація за алфавітом

- **🌐 Веб-інтерфейс** — сучасна темна панель на базі Flask:
  - Інтерактивний редактор змісту
  - Логи генерації в реальному часі через Server-Sent Events (SSE)
  - Керування конфігурацією (модель, провайдер, тема)

- **💻 Режим CLI** — повноцінний інтерфейс командного рядка для автоматизованих запусків

- **🔌 Розширювана система провайдерів** — абстрактний базовий клас для AI провайдерів; легко замінити модель OpenAI GPT або додати нових провайдерів (Gemini, Anthropic тощо)

- **⚙️ YAML конфігурація** — централізований конфіг для моделей, параметрів генерації, налаштувань проєкту та методичних рекомендацій

## Технології

| Рівень | Технологія |
|--------|-----------|
| AI / LLM | OpenAI GPT (gpt-4.1-mini, gpt-4o тощо) |
| Веб-дослідження | DuckDuckGo Search API |
| Управління токенами | tiktoken |

| Оновлення в реальному часі | Server-Sent Events (SSE) |

| Конфігурація | YAML + python-dotenv |
| Експорт документів | python-docx |

## Початок роботи

### Передумови

- Python 3.10+
- OpenAI API ключ

### Встановлення

```bash
# Клонувати репозиторій
git clone https://github.com/solabuch/kursova_generator.git
cd kursova_generator

# Створити та активувати віртуальне середовище
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

# Встановити залежності
pip install -r requirements.txt
```

### Налаштування

1. Створіть файл `.env` у корені проєкту:
```env
OPENAI_API_KEY=sk-proj-ваш-ключ
```

2. Відкоригуйте параметри в `config.yaml`:
```yaml
active_provider: openai

providers:
  openai:
    model: "gpt-4.1-mini"    # або gpt-4o, gpt-3.5-turbo тощо
    generation_params:
      temperature: 0.7
      max_tokens: 10000

project_settings:
  topic: "Ваша тема дослідження"
```

## Використання

### 🌐 Веб-інтерфейс (Рекомендовано)

```bash
python web/app.py
```

Відкрийте браузер за адресою `http://127.0.0.1:5000` — застосунок автоматично відкриє браузер при запуску.

Веб-панель дозволяє:
- Редагувати зміст у візуальному редакторі
- Налаштовувати AI модель та параметри генерації
- Слідкувати за прогресом генерації з логами в реальному часі
- Відкривати папку з результатами прямо з інтерфейсу

### 💻 Командний рядок

```bash
python main.py --topic "Ваша тема дослідження"
```

### Результати

Згенеровані файли зберігаються в директорії `output/`:
- `_final_course_paper.txt` — повний текст роботи з перенумерованими посиланнями
- `_sources.txt` — список джерел, відсортований за алфавітом
- Окремі файли розділів для перевірки

## Як це працює

1. **Парсинг** — парсер змісту зчитує зміст і будує ієрархічну структуру з нумерацією розділів
2. **Планування** — агент-планувальник аналізує кожен розділ, класифікує як теоретичний або практичний та визначає сутності для дослідження
3. **Дослідження** — дослідник виконує пошук через DuckDuckGo для збору релевантних даних, статистики та інформації
4. **Генерація** — агент-автор створює текст для кожного розділу з використанням спеціалізованих промптів, дослідницьких даних та контексту розмови
5. **Збірка** — всі розділи об'єднуються у фінальний документ із перенумерацією посилань відповідно до алфавітно відсортованого списку джерел
