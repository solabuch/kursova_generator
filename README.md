## Встановлення

1.  Клонуйте репозиторій: `git clone <URL_репозиторію>`
2.  Перейдіть до папки проєкту: `cd kursova_generator`
3.  Створіть та активуйте віртуальне середовище (рекомендовано):
    ```bash
    python -m venv venv
    source venv/bin/activate  # Linux/macOS
    # venv\Scripts\activate  # Windows
    ```
4.  Встановіть залежності: `pip install -r requirements.txt`

## Налаштування

1.  **API Ключі:** Відредагуйте файл `config.yaml`. В розділі `providers` для потрібних вам AI (наприклад, `openai`) вкажіть ваш `api_key`. **НЕ ЗБЕРІГАЙТЕ КЛЮЧІ В СИСТЕМІ КОНТРОЛЮ ВЕРСІЙ (GIT)!** Краще використовувати змінні середовища або інші безпечні методи зберігання.
2.  **Провайдер:** В `config.yaml` встановіть `active_provider` на ім'я провайдера, який ви хочете використовувати (наприклад, `openai`).
3.  **Модель:** Вкажіть бажану модель для обраного провайдера (наприклад, `gpt-4o`).
4.  **Проєкт:** В секції `project_settings` вкажіть шлях до вашого файлу змісту (`input_toc_file`), папку для результатів (`output_dir`), шаблон промпту (`prompt_template_file`), тему роботи (`topic`) та основні методичні вимоги (`methodology_summary`).
5.  **Зміст:** Створіть файл змісту (наприклад, `input/toc.txt`) у форматі, описаному вище (текст з відступами).
