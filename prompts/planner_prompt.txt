Проаналізуй кожен пункт змісту і поверни JSON масив об'єктів для кожного розділу/підрозділу.
Формат об'єкту:
{{
  "number": "Номер розділу як в змісті (наприклад '1.1' або 'Розділ 2')",
  "type": "theoretical" або "practical",
  "entities": ["Список", "конкретних", "назв", "підприємств"],
  "research_needed": true або false,
  "guidance": "Короткі вказівки для агента-виконавця, що саме тут писати"
}}

Правила:
1. "theoretical" - для вступу, оглядів літератури, теоретичних основ. Вимагає академічного стилю, definitions.
2. "practical" - для аналізу підприємства, розрахунків, рекомендацій. Вимагає ТАБЛИЦЬ, конкретних даних.
3. Якщо в назві розділу є назва компанії (наприклад "готель Надія"), додай її в "entities" і постав "research_needed": true.
4. Поверни ТІЛЬКИ JSON масив без зайвого тексту.
